# TaiXiuLiveHit

Ứng dụng WPF .NET 8 tự động hóa Tài/Xỉu Live qua WebView2, hỗ trợ chạy độc lập và plugin AutoBetHub/ABX.

## Tài liệu

- `PROJECT_CONTEXT.md`: phạm vi và invariant.
- `CURRENT_STATE.md`: snapshot ngắn của trạng thái hiện tại.
- `ARCHITECTURE.md`: module và runtime flow.
- `BUSINESS_RULES.md`: rule nghiệp vụ.
- `TODO.md`, `BUGS.md`: việc còn lại và rủi ro có bằng chứng.
- `AGENTS.md`: hướng dẫn cho AI coding trong project.

Build target và dependency nằm trong `TaiXiuLiveHit.csproj`.
